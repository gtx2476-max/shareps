# Spheres (Purpur / Paper 1.21.8, Java 21)

Сферы — головы с эффектами. Держишь сферу в руке (основная или левая) — работают бафы/дебафы и особые удары.

## Установка
`mvn package` -> `target/Spheres.jar` -> в `plugins/` (или залей на GitHub, вкладка Actions соберёт jar).

## Команды
- `/spheres` (`/sphere`) — красивое меню; клик по сфере показывает рецепт крафта. Право `spheres.use` (всем)
- `/spheres give <игрок> <id|all> [кол-во]`, `/spheres reload` — `spheres.admin`

## Сферы
| Сфера | Эффект |
|---|---|
| Пустая | основа всех сфер. Крафт: 9 голов игроков (головы падают при убийстве игрока) |
| Фугу | зелёный круг (радиус 2) — враги внутри: Отравление, Замедление II |
| Посейдона | 40% при ударе замедление врага; +4 брони, -4 HP, подводное дыхание |
| Аида | удары/стрелы/меч поджигают; 18% большой фаербол; Скорость I, огнеупорность, -3 брони |
| Зевса | 4% молния при ударе мечом; Спешка I, -2 брони |
| Гермеса | Скорость II, Прыгучесть I, -6 HP |
| Афины | Сопротивление I, -2 урона |

Крафт любой сферы: пустая сфера в центре + 8 ингредиентов (3x3):
`C E C / E S E / C E C` (S = пустая сфера). Аид: C = порошок Блейза, E = блок магмы.
Остальные: Фугу (паучий глаз / иглобрюх), Посейдон (раковина наутилуса / кристаллы призмарина),
Зевс (золотой слиток / громоотвод), Гермес (сахар / перо), Афина (алмаз / железный блок).

## Текстуры голов
По умолчанию стоят временные головы мобов (MHF_*). Красивые текстуры: на minecraft-heads.com найди голову,
скопируй Value (base64) или хеш текстуры (64 символа) в `config.yml` -> `textures.FUGU` и т.д., затем `/spheres reload`
и выдай сферы заново. Всё остальное (шансы, уровни, радиус) тоже в `config.yml`.

## Структура кода (для интеграции / ИИ)
- `SphereType` — enum всех сфер: имя, лор, рецепт (corner/edge). Новая сфера = новая строка + логика.
- `SphereItems` — создание предметов, `typeOf(ItemStack)` (метка в PersistentDataContainer `spheres:sphere`).
- `SpheresManager` — тик 5 игровых тиков: `active(Player)`, пассивные эффекты, атрибуты, аура Фугу.
- `SphereListener` — удары (Посейдон/Аид/Зевс), стрелы, дроп голов, защита крафта, запрет ставить сферы.
- `SphereMenu`, `SpheresCommand` — меню и команды. API: `SpheresPlugin.getInstance().getItems().create(SphereType.ZEUS)`.
